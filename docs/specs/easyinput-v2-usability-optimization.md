# EasyInput V2 使用体验优化

## 本轮范围

用户反馈5灯刺眼，并授权优化灯光、识别诊断、长回复缓存与错误提示。

- 在5灯统一输出入口，将原来最大50的颜色通道除以4，最大12；白色音量条、连接、录音、
  合成、播放、静音及错误提示都经过相同限亮。独立联网绿灯保持现有GPIO驱动。
- 错误提示延长至6秒；红灯数量1表示识别/录音，2表示语音合成，3表示播放，5表示其他错误。
- 启用Qwen-TTS时，将每条回复的PSRAM文本缓存由1KiB扩大至8KiB，8条消息合计64KiB。
  超出8191字节时明确报 `TTS REPLY TOO LONG`，不静默截断或发送截断UTF-8。
- 采音上传使用已有的有界等待接口；写入不完整或I2S读取失败时拒绝提交残缺录音，显示录音错误。
- 记录麦克风样本数、峰值、均方值、削顶数量，便于判断弱音、失真与缺失；不更改采样率、
  引脚、增益、ASR模型或语言设置，不能声称识别准确率已经提高。

## 验收与边界

编译通过；实机确认5灯不再刺眼、颜色可辨，短句录音与朗读正常、日志无音频缺失；
长回复超过旧1023字节限制时能够提交合成。错误分类与6秒提示需要错误场景实测。
所有测试结果仅在实际完成后填写。

8KiB文本仍有上限；TTS仍保留4MiB PCM上限和原有会话超时，不能承诺任意长度完整朗读。
本轮不增加自动重试、备用服务、系统配置或依赖。
