# Spec：S8一键AI故事机

日期：2026-10-17。用户选择先实现故事机，并指定6～9岁、情节更丰富。新闻早餐机及S5长按新闻不在本轮实现范围。

## 交互与内容

- 已配对且正常就绪时短按S8，向Muse发送固定的故事生成文字请求，再用已有Qwen-TTS播放。无需麦克风录音、唤醒词或ASR；每次请求一个新故事，不是播放预录的“昨天原文”。
- 适合6～9岁，每次请Muse自行选择新的主角、场景和情节，不固定小萤火虫；约200～250字，包含起因、小困难、主动解决和温暖结尾，情节具体但不惊吓。只输出标题和正文，避免前置说明及续写追问。字数及内容不重复均为请求约束，不保证模型严格遵守，不裁切不完整故事、不新增自动重试或重复检测服务。
- 配对确认优先于故事；未配对仍进入原配对流程，S8长按约5秒仍执行原恢复设置，短按释放判定及长按不再触发短按保持原样。
- 静音时不启动故事。正在录音、识别、等待或播放时，重复S8不叠加请求。离线时沿用S5本地状态反馈与重试请求，不生成虚假的故事完成提示。
- S4沿用现有等待阶段取消／播放阶段暂停；S3续播或播完从头重播。S1可打断故事进入原按住说话流程。故事缓存沿用4MiB上限，不承诺所有超长输出均能完整重播，不新增静默截断或自动换服务。

## 音频、灯光与共存

在原语音任务中执行故事事件，沿用唤醒停止、电台暂停、播放器及回复结束后的释放逻辑，不在按键回调发网络请求。TTS与Qwen朗读配置原样保留；TTS故障沿用现有错误提示，不回退到别的服务。

生成、缓冲和播放时显示低亮度暖色呼吸，继续受用户保存的亮度限制；静音、错误、音量调节及电台灭灯仍优先。故事完成或暂停后回到原空闲显示，S3重播故事仍显示暖色；下一次S1/离线唤醒问答恢复原问答灯效，不修改全局亮度或音量。

故事请求作为“可朗读文字轮次”处理，保留原串口文字轮次不朗读行为。新增入口只在当前EasyInput、Muse会话及Qwen-TTS组合编译，其他板型不接入S8故事。取消代次用于隔离过期故事命令，命令失败释放复制文本，不启动ASR。

## 验收标准

1. 配对中S8仍确认；长按恢复设置后释放不触发故事；普通就绪短按一次恰好一个故事请求，忙碌时重复按不排队。
2. 日志无该故事对应ASR请求；Muse文字回复与喇叭朗读内容一致，符合目标年龄与温和内容要求，字数/时长按实测记录。
3. S4暂停、S3续播及完成后重播正常，S1打断后进入正常问答且清除故事灯效；错误或取消不残留忙碌状态。
4. 故事生成/播放时暖色柔光、音量和静音保持；联网状态反馈不抢播；电台暂停并在整轮结束后回到直播点。
5. 记录内部RAM、PSRAM、故事请求耗时及取消/重复操作；不以编译或静态检查通过替代实体结果。

## 执行边界

仅实现、检查及复用现有受限环境编译，不安装依赖、不修改全局配置、不生成额外提示音、不调用云端故事或TTS。本轮用户没有确认烧录；正式试播会使用现有Muse/Qwen服务，费用与调用范围在实际测试前确认。
